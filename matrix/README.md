# Matrix / Element — друга двері до агента

Той самий агент, що й у Telegram (той самий репозиторій, ті самі скіли, пам'ять і інструменти),
але через Matrix-клієнт [Element](https://element.io). Окремий процес: якщо ця двері впаде,
Telegram-бот працює далі.

Кожна кімната — окрема незалежна розмова зі своєю сесією.

---

## Що потрібно

- Сервер, де вже стоїть `lil_worker` і авторизований Claude Code CLI (`claude login`)
- Окремий Matrix-акаунт **для бота** + твій власний акаунт
- Свій homeserver **не потрібен** — безкоштовний акаунт на matrix.org підходить:
  [app.element.io](https://app.element.io)

---

## Встановлення — одна команда

```bash
cd ~/lil_worker
bash matrix/setup.sh
```

Скрипт зробить усе сам і запитає лише те, що не може дізнатись:

1. Адресу homeserver (за замовчуванням `https://matrix.org`)
2. Логін і пароль бота — **токен доступу він отримає сам**, лазити в налаштування Element не треба
3. Твій MXID (вигляду `@ty:matrix.org`) — тільки цей акаунт зможе спілкуватися з ботом
4. Попросить створити кімнату і запросити туди бота → **сам прийме запрошення** і покаже список
   кімнат на вибір, за назвами. Внутрішній ID кімнати шукати не треба
5. Модель і (за бажанням) ключ OpenAI для голосових
6. Запропонує поставити systemd-сервіс і одразу запустить

Після запуску бот сам напише в кімнату, що міст піднято. Далі просто пиши йому.

Повторний запуск скрипта безпечний — попередні значення підставляються як варіант за замовчуванням.

**Важливо:** кімнату створювати **без шифрування** (E2EE вимкнути при створенні — потім це
незворотньо). Ця версія мосту зашифровані кімнати не читає; скрипт попередить, якщо вибрана кімната
зашифрована.

## Після встановлення

```bash
tail -n 50 matrix/logs/matrix-bridge.log   # логи
matrix/restart_bridge.sh                   # перезапуск (відмовиться, поки крутяться фонові задачі)
matrix/run.sh status                       # стан процесу
```

Команди в кімнаті:

- `/new` — скинути сесію ЦІЄЇ кімнати (інші не чіпає)
- `/status` — модель, сесія, кількість кімнат, активні фонові задачі
- `/jobs` — довгі фонові задачі та їхній стан

Все інше йде агенту як звичайне повідомлення. Підтримуються фото, голосові, файли.

---

## Кілька кімнат

У `matrix/.env` ключ `ALLOWED_ROOM_ID` приймає кілька id через кому — наприклад робоча кімната і
окрема «читалка». Кімнати працюють паралельно, кожна зі своєю сесією. Setup дозволяє вибрати
кілька одразу (`1,3`).

---

## Свій homeserver

Скрипт працює з будь-яким homeserver — просто вкажи його URL замість matrix.org. Розгортання
власного сервера (Docker, TLS, nginx) у цей репозиторій не входить.
